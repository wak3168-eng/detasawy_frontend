# Onboarding question audio

Drop one MP3 per step here, recorded in spoken Pashto. The speaker button
appears automatically on a step as soon as its file exists — no code changes.

| File           | Question it voices                          |
| -------------- | ------------------------------------------- |
| `welcome.mp3`  | Welcome — "a few quick questions"           |
| `country.mp3`  | Where are you from? (ته د کوم ځای يې؟)      |
| `province.mp3` | Which province? / Where do you live?        |
| `district.mp3` | Which district?                             |
| `tehsil.mp3`   | Which tehsil?                               |
| `city.mp3`     | Which city? (overseas)                      |
| `tribe.mp3`    | Your tribe?                                 |
| `lineage.mp3`  | Do you know the sub-tribe?                  |
| `language.mp3` | Which language do you speak at home?        |
| `photo.mp3`    | Add a photo?                                |

Keep clips short (2–4 seconds), mono, ~64 kbps is plenty.
